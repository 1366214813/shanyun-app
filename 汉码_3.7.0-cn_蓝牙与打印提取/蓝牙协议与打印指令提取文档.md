## 2. 蓝牙连接协议

### 2.1 Classic SPP
- UUID(主): `00001101-0000-1000-8000-00805F9B34FB` (标准 SPP)
- 使用 `createInsecureRfcommSocketToServiceRecord(MY_UUID)` 连接, 不安全通道
- OpenPort 先 `cancelDiscovery()` (最多等 500ms)
- 读写: `InputStream/OutputStream`, 分包上限 `bluetooth = 1024` 字节/次
- 读线程 `Readerthread` 循环收集到全局 `readData1`, `Isokread` 标记
- `IsReConnect` 支持断线重连

### 2.2 BLE (GATT)
- 备用 UUID: `0000ff13-0000-1000-8000-00805F9B34FB`
- 连接: `BleManager.buildBleDeviceByDeviceAddress(mac)` + `connect()`
- 关键: 服务/特征 UUID 不是写死的, 由 UI 扫描设备 GATT 服务后,
  取第一个可写节点作为写通道 (`serviceUUID`/`characteristicUUID`),
  第一个可读节点作为通知通道 (`serviceNotifyUUID`/`characteristicNotifyUUID`)
- 写数据: `BleManager.writeData(device, serviceUUID, characteristicUUID, data)` 
  同步等待回调 (每 50ms 轮询一次结果标记)
- 读数据: `BleManager.readData(device, notifyService, notifyChar)` 订阅通知

### 2.3 握手 ChackHands
`Check.ChackHands(n, m)` 发送 6 字节:
```
1B 1C 73 65 74 20 6D 6D  n  m     (ESC + "set mm" + n + m)
```
即 `0x1B 0x1C "set mm" n m`。
预期收到响应 `0x4F 0x4B` = "OK", 成功返回 0;
无响应按 2 秒超时返回 -1。`BTOperator.ChackHandsTest` 同款。
n 为索引、m 通常为 0/1。连接建立后 app 发送握手确认打印机在线。

### 2.4 传输通道参数
| 项 | 值 |
|---|---|
| SPP 分包大小 | 1024 字节 |
| BLE 分包大小 | 1024 字节 (BLE library 内部按 MTU 再分) |
| 写同步轮询 | 50ms |
| 压测状态轮询 | PrintActivity.getStatus() 循环 1s |
| ReadData 超时 | `SetReadTimeout`, 测试 1000ms/2000ms |

## 3. V1 扩展指令协议 (ESC & V1)

框架格式 (ASCII 命令带 CR LF):
```
ESC & V1 <cmd> "<param>" CR LF     即 1B 1C 26 20 <cmd> 20 22 <param> 22 0D 0A
```

已知命令:
| 命令 | hex | 用途 |
|---|---|---|
| `ESC & V1 getkey \r\n 01 ca 00 01` | `1b 1c 26 20 67 65 74 6b 65 79 0d 0a 01 ca 00 01` | getHeadControlMethod, 返回头控方式([0]) |
| `ESC & V1 getval "printer_version" \r\n` | `1b 1c 26 20 56 31 20 67 65 74 76 61 6c 20 22 70 72 69 6e 74 65 72 5f 76 65 72 73 69 6f 6e 22 0d 0a` | 查询版本 (type 0) |
| `ESC & V1 getval "auto_wifi" \r\n` | `1b 1c 26 20 56 31 20 67 65 74 76 61 6c 20 22 61 75 74 6f 5f 77 69 66 69 22 0d 0a` | 查询 WiFi 配置 |
| `ESC & V1 do "refresh_data" \r\n` | `1b 1c 26 20 56 31 20 64 6f 20 22 72 65 66 72 65 73 68 5f 64 61 74 61 22 0d 0a` | 刷图头 (bb_saveHead) |
| `ESC & V1 set mm <n> <m>` | `1b 1c 73 65 74 20 6d 6d n m` | 握手 (见 2.3) |
| `ESC & V1 do "print" \r\n` | (推断同款 `do "print"`) | 触发打印 |

版本查询具体逻辑 (getVersion):
- type 0: 先发 getval `printer_version`, 200ms 读响应 -> 若 ≥1 字节作为版本
  没响应则降级发 `0x1b 0x12 0x56`, 取头 10 字节
- type 1: 发 `0x1b 0x12 0x56`
- type 2: 发 `0x1b 0x12 0x64`, 用 `PoliDeviceDetailsParser` 解析固件详情

## 4. 状态查询协议

### 4.1 常规状态字节
`getPrintStatus(1)`: 发送后读取并解析返回首 2 字节, `ByteUtils.bytes2ToInt_l`
低字节在前得到状态码, 与 `PrinterStatus` 常量比对 (打印中/缺纸/开盖等).

### 4.2 状态文本过滤器 (DataFilter)
返回数据里匹配以下关键字后提取值:
```
pooli_sta=, pooli_study=, nfc_uid, nfc_verify_info=, nfc_ribbon_type,
nfc_ribbon_len, rbbnd, status:, rtsts
```
用于纸仓/色带/浓度/NFC 校验等状态展示。

## 5. WiFi 配置协议

- 查询: `ESC & V1 getval "auto_wifi" \r\n`
- 设置: `CommandData.setWifiCommand` 按字段构造:
```
WM:xxx  -> 模式 ?
WS:xxx  -> SSID (≤28 字节)
WP:xxx  -> 密码
WA:xxx  -> 认证方式?
```
- SSID / 密码长度限制 ≤28 字节; 并发往打印机执行
- 网络打印: `WiFiOperator` 走 TCP `Socket(InetSocketAddress(ip, 9100))` 原始流

## 6. 图像/位图数据打包 (PrinterDataCore)

字节序: 
- int (宽度/长度等) 一律小端 2 字节 (B/ 高低序)
- 设备实际 DPI: `PrinterDataCore` 内部扩展到每点 1bit 的物理分辨率

关键方法:
- `EspaceHeighLine` -> 差分行/间隔行
- `CompressData4`: 从左到右, 将 4 字节宽度压缩为 <0x80 的短游程; 
  高位 `(b & 0x80)==0` 表示重复计数 `b&0x7F`, 否则按字节拷贝
- 可配置压缩模式 `PrintCompressModel`: 
  - 0 = CompressPrintData (原始压缩)
  - 1 = AddPrintCode (按命令码头打包)
  - 2 = AddPrintNVImage (走 NV 图)
  - 3 = LZO 压缩 (依赖 libLZO.so / JNI)

打印流程数据头尾:
```
[命令码尾帧] 图形数据 `PrintDataFormat(bitmap, headX, headY, wcm, hcm, gap)`
[刷新] bb_saveHead = "1B 1C 26 20 56 31 20 64 6F 20 22 72 65 66 72 65 73 68 5F 64 61 74 61 22 0D 0A"
双色: HPRTPrinterHelperV1 将双面色数据二段打包, getPackLength 返回每包长,
      sendTaskData/sendTaskEnd 一包一包发
```

### 6.1 走纸
`setPrintFeed(feed)` 发送 `0x1B 0x1B 0x01 lo hi` (走纸量小端 2 字节)
`setPrintFeed(0)` = 裁切/出标签

## 7. TSPL 指令集 (面单, TSPLPrinterManager)

文本型命令, 每行以 CR LF 结尾:
```
SIZE 100mm,150mm      // 页面尺寸
CLS                   // 清空缓存
DENSITY N             // 浓度 (DENSITY = 4*density-1)
GAP 3mm,2mm           // 间隙
DIRECTION 1|0         // 方向
TEXT x,y,font,rotate,x_mul,y_mul,"abc"
BARCODE x,y,type,height,readable,rotate,x_mul,y_mul,"data"
QRCODE x,y,model,size,mode,"data"
PDF417 x,y,w,h,...
BITMAP x,y,w,h,data
PRINT n[,n]           // 打印份数
FORMFEED / EOP
```
- 汉字: 经 `TextEncoding.GBK` 编码; 中文字库名如 "TS0"、"Proribbon-8x16" 等
- 位图: 每行字节数按宽度换算, 逐行发 `BITMAP` 数据
- 完成: 发 `PRINT <n>` + `CLS`；面单场景还会先 `SIZE`/`LOCATE`

## 8. ESC 指令集 (小票, ESCPrinterManager)

二进制指令 (0x1B = ESC, 与 V1 无关):
```
ESC @               (0x1B 0x40)  初始化
ESC a n             (0x1B 0x61)  对齐 0/1/2 (SetJustification)
ESC E n             (0x1B 0x45)  加粗
ESC ! n             (0x1B 0x21)  打印模式
ESC 3 n             (0x1B 0x33)  行距
ESC J n / FF        (0x0C)       进纸/打印
ESC 2               (0x1B 0x32)  默认行距
GS ! n              (0x1D 0x21)  倍宽倍高
GS H n              (0x1D 0x48)  HRI 位置
GS h n              (0x1D 0x68)  条码高度
GS k <type> <len> <data>         条码
GS ( k ...                       二维码
GS v 0 m xL xH yL yH data         位图
ESC d n             (0x1B 0x64)  走纸 n 行
ESC p m t1 t2                    (0x1B 0x70) 蜂鸣/钱箱
```
- 浓度 `setDensity`: `0x1B 0x79 (density-1)`; `setCloseMode` 等
- 打印文本按 `ESCPrinterManager.addText` 逐行拼装, 编码 GBK/UTF-8
- 完成后发 `GS ( 0x0B` / 走纸换行触发打印

## 9. CPCL 指令集 (CPCLPrintManager / CPCLT260 / CPCLA200U)

```
! 0 200 200 n1 n2        // 分辨率 + 页面宽度
PAGE-WIDTH n             // 页面宽
GAP-SENSE n1,n2 / TEAR-OFF
SETMAG / TEXT / CENTER / RIGHT / JUSTIFY
MAG 2 2
TEXT 4 0 0 0 "abc"       // 点阵文本
BARCODE / BARCODE128/x   128 "data"
IMAGE / BITMAP x y w h
FORM
PRINT n
```
- T260 变体带自己的页宽/间隙设置 (`SET PITCH`, `SET CONTRAST`)
- A200U 使用 JPEG/PDF 打印 (libpdfiumandroid.so)

## 10. ZPL (ZPLPrintManager)

标准 ZPL 命令:
```
^XA ^LL n ^FO x,y ^A0N.. ^FD text ^FS ^BY.. ^BC.. ^FD.. ^FS ^XZ
```
图形以 ^GF 8,1 逐字节位图; 双色机型追加第二色 ^GF。

## 11. 机型/指令集映射 (PrinterMapping + HPRTConst)

| 指令名 | 常量 |
|---|---|
| `ESC` / `ESC_POLI` | MODEL_ESC_DEX=1, MODEL_ESC_ALL=2 |
| `TSPL` | MODEL_TSPL_3=3, MODEL_TSPL_16=4 |
| 不支持 | MODEL_UN_SUPPORT=5 |
| ZPL | MODEL_ZPL_COMPRESS=6 (压缩位图) |
| `CPCL` / `T260CPCL` | CPCL 系列 |

`PrinterMapping` 字段 (服务端下发配置, Gson `@SerializedName`):
```
name, instruct, compress(1=压缩), encryption(0/1),
printerHeadWidth, printerDpi, subContract,
bicolor_print, compressModelList[PrintCompressModel]
```

机型 ID (HPRTConst): e.g. TP801=4097, R420=4098...

`PrintManagerFacade` 路由逻辑:
```
instruct=ESC        -> ESCPrinterManager (SC/小票)
TSPL                -> TSPLPrinterManager (面单)
CPCL                -> CPCLPrintManager
ZPL                 -> ZPLPrintManager
CPCL_T260           -> CPCLT260PrintManager
含 "SUNMI" 厂商      -> Sunmi*PrinterManager (走厂商 SDK)
TL31W / A200U 特配   -> 专用管理器
```
`PrinterInstructionHolder` 根据打印场景选中 "TSPL" (面单) 或 "ESC" (小票);
老机型升级协议时通过 `PrinterInstructionHolder.setInstruction` 下发。
